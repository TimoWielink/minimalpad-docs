Every MinimalPad uses the same PCB, the same 4×4 key layout, the same rotary encoder, and runs the same ZMK firmware. The differences come down to how much of the build you want to do yourself, and which controller you choose. Both paths end up at the same desk experience — 16 programmable keys, wireless operation, and browser-based configuration through MinimalPad Studio.

## DIY kit

The MinimalPad Kit includes the PCB, rotary encoder, push button, Kailh Choc hot-swap sockets, and diodes — everything you need on the PCB side. You choose the controller, switches, keycaps, and case. The SMD components are pre-soldered, so your job is to complete the through-hole assembly with a soldering iron.

**Good choice if you:**
- Enjoy building keyboards or electronics as part of the hobby
- Want to choose your own switches, keycaps, and case
- Are looking for the most affordable entry point
- Want to learn basic keyboard assembly

**Be aware:** soldering always carries some risk of cold joints or bridged connections. The MinimalPad's 16-key layout is intentionally approachable — it's a manageable first soldering project — but you verify the build yourself. If something doesn't work, the build guide and support team are there to help you troubleshoot.

Visit [minimalmacropad.com](https://www.minimalmacropad.com/) for current pricing, available configurations, and optional add-ons.

## Fully assembled

Every assembled MinimalPad is hand-built, soldered, flashed with firmware, and individually tested before it ships. Every key is verified, the encoder is checked, and the board is inspected. When it arrives, plug it in and open Studio — it's ready to customise.

Because each unit is built to order from Amsterdam, shipping typically takes around one week.

**Good choice if you:**
- Want a finished, tested device with no assembly required
- Don't own a soldering iron or prefer not to solder
- Need something reliable for a professional setup on day one

Visit [minimalmacropad.com](https://www.minimalmacropad.com/) for current pricing, available configurations, and estimated ship times.

## NRF52840 clone vs. Nice!Nano V2

Both controller options are built around the same Nordic nRF52840 chip and run the exact same ZMK firmware. You'll get identical Bluetooth connectivity, wireless operation, battery monitoring, and Studio compatibility either way. The practical differences are about manufacturing quality and long-term confidence.

| | NRF52840 Clone | Nice!Nano V2 |
|---|---|---|
| Chip | nRF52840 | nRF52840 |
| ZMK compatibility | Full | Full |
| Bluetooth + wireless | Yes | Yes |
| Battery monitoring | Yes | Yes |
| Manufacturing standard | Cost-effective | Higher — the original community reference board |
| Community support | General ZMK community | Large, dedicated Nice!Nano community |
| Best for | First builds, cost-conscious buyers | Anyone wanting the reference-grade controller |

Day to day, you won't notice a functional difference. Start with the clone if you're building your first macropad or keeping costs down. Choose the Nice!Nano V2 if you want the original board that the wider ZMK community is built around.

<Note>
  The controller does not affect how MinimalPad Studio works. Both options connect and configure identically through the browser.
</Note>
