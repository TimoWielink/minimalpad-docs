The Single Key category lets you assign any individual keystroke to a MinimalPad key. This covers the full range of keys you'd find on a standard keyboard — letters, numbers, function keys, navigation keys, and more.

## Assign a single key

<Steps>
  <Step title="Open Studio and connect your MinimalPad">
    Go to [studio.minimalmacropad.com/configure](https://studio.minimalmacropad.com/configure) in Chrome or Edge, then connect via USB or Bluetooth.
  </Step>
  <Step title="Click the key you want to assign">
    Click any key on the on-screen layout. The action picker opens on the right.
  </Step>
  <Step title="Choose the Single Key category">
    Select **Single Key** from the action category picker.
  </Step>
  <Step title="Select a key">
    Browse or search for the key you want to assign and select it.
  </Step>
  <Step title="Click Assign">
    The key is applied immediately so you can test it right away.
  </Step>
  <Step title="Save your changes">
    Click **Save** to write the assignment to your MinimalPad's flash memory.
  </Step>
</Steps>

## Available key types

**Letters**
A through Z. Output follows your OS keyboard layout — see the note below.

**Numbers**
0 through 9.

**Symbols**
Characters like `!`, `@`, `#`, `$`, `%`, `^`, `&`, `*`, `(`, `)`, `-`, `=`, `[`, `]`, `\`, `;`, `'`, `,`, `.`, `/`. Actual output depends on your OS keyboard layout setting.

**Function keys**
F1 through F24.

**Navigation keys**
Arrow keys (Up, Down, Left, Right), Home, End, Page Up, Page Down.

**Control keys**
Escape, Enter, Tab, Backspace, Delete, Space, Insert.

**Lock keys**
Caps Lock, Scroll Lock, Num Lock.

**System keys**
Print Screen, Pause/Break.

**Modifier keys (standalone)**
Shift, Ctrl, Alt/Option, Cmd/Win (GUI). Assigning a modifier as a standalone key sends that modifier alone when pressed.

<Note>
  Key output depends on your operating system's keyboard layout setting. If your OS is configured for a non-US layout (such as AZERTY, QWERTZ, or a regional variant), symbol and letter keys may produce different characters than the labels suggest. MinimalPad sends hardware key codes — the OS layout determines what character appears on screen.
</Note>

<Tip>
  Combine Single Key assignments with layers to give the same physical key a different function depending on context — for example, an arrow key on one layer and a function key on another. See [Layers](/studio/layers) to learn how.
</Tip>
