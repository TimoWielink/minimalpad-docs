MinimalPad has 16 RGB LEDs underneath the case that produce an underglow effect. You control the lighting by assigning RGB action keys in MinimalPad Studio — when you press those keys on the pad, the lighting changes on the device in real time.

<Note>
  Studio assigns RGB action keys to your layout. It does not provide a live color picker or a preview panel. To adjust the lighting, press the assigned keys on your MinimalPad itself and watch the result directly on the device.
</Note>

## Assign an RGB action

<Steps>
  <Step title="Open Studio and connect your MinimalPad">
    Go to [studio.minimalmacropad.com](https://studio.minimalmacropad.com/) in Chrome or Edge, then connect via USB or Bluetooth.
  </Step>
  <Step title="Click the key you want to assign">
    Click any key on the on-screen layout. The action picker opens on the right.
  </Step>
  <Step title="Choose Device Controls">
    Select **Device Controls** from the action category picker, then browse the RGB actions.
  </Step>
  <Step title="Select an RGB action">
    Choose the action you want from the table below.
  </Step>
  <Step title="Click Assign">
    The action is applied immediately.
  </Step>
  <Step title="Save your changes">
    Click **Save** to write the assignment to your MinimalPad's flash memory.
  </Step>
</Steps>

## Available RGB actions

| Action | What it does |
|---|---|
| Toggle | Turns lighting on if it is off; turns it off if it is on |
| Turn On | Turns lighting on |
| Turn Off | Turns lighting off |
| Hue + | Shifts the color hue upward through the spectrum |
| Hue − | Shifts the color hue downward through the spectrum |
| Saturation + | Increases color saturation (more vivid) |
| Saturation − | Decreases color saturation (more neutral) |
| Brightness + | Increases LED brightness |
| Brightness − | Decreases LED brightness |
| Speed + | Speeds up the current animation |
| Speed − | Slows down the current animation |
| Next Effect | Cycles forward to the next lighting animation |
| Previous Effect | Cycles back to the previous lighting animation |

## Automatic power saving

The RGB LEDs turn off automatically after 30 seconds of inactivity to conserve battery. They resume as soon as you press any key.

<Tip>
  Assign **Brightness +** and **Brightness −** to two adjacent keys on a dedicated layer for quick access. If you use the encoder, you can also configure the encoder press to toggle the lighting on and off — see [Encoder](/studio/encoder) for details.
</Tip>
